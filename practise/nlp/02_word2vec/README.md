# 02 — Word2Vec (Skip-Gram + negative sampling) с нуля

`word2vec.py`: словарь и частоты, пары Skip-Gram по окну, распределение негативов $P_{neg}(w) \propto f(w)^{0.75}$, модель `SGNS` с двумя наборами векторов (`center` — v, `context` — u; инициализация как в оригинальном word2vec), обучение Adam со свежими негативами на каждый батч, `most_similar` по косинусу центральных векторов. Корпус синтетический (`make_toy_corpus`): 3 темы (животные / еда / транспорт) плюс служебные слова, в каждой теме одно редкое слово.
Тесты: `pytest -q` из этой папки. Пары сверяются с явным списком, $P_{neg}$ — с формулой, loss — с ручным расчётом и со стартовым значением $(1+K)\ln 2$, плюс градиент только по строкам батча, падение loss при обучении, косинус против скалярного произведения в `most_similar`.
`experiments.ipynb`: статистика корпуса, сравнение частот с $P_{neg}$, loss до обучения, кривая loss, ближайшие соседи (частые, редкое, служебное слово), PCA центральных векторов на плоскость.
