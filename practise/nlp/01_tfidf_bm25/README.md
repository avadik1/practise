# 01 — TF-IDF и BM25 с нуля

`retrieval.py`: `TfidfRetriever` (как `sklearn.TfidfVectorizer()` по умолчанию: сглаженный idf, L2-нормировка, поиск по косинусу) и `BM25` (Okapi, idf в варианте Lucene, параметры `k1`, `b`).
Тесты: `pytest -q` из этой папки. TF-IDF сверяется со sklearn, BM25 — с явной формулой в тесте плюс свойства (насыщение по tf, роль `k1` и `b`).
`experiments.ipynb`: корпус поддержки интернет-магазина — редкий точный токен (`0x80070057`), промах на синонимах и словоформах, короткий документ против длинного при разных `k1`/`b`, график насыщения по tf.
