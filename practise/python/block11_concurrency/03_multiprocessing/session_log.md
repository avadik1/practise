### Попытка 1 (19:44+) — все три функции сразу
`pytest -q`: 33 failed, 42 passed.

- **make_chunks** — формула границ через `min_group`/`residual` верная для N ≥ K. Ошибки:
  - нет проверки `n_chunks < 1` → K=0 даёт `ZeroDivisionError` вместо `ValueError`, K=-1 молча возвращает `[]`;
  - при N < K цикл идёт по `range(n_chunks)` → хвостовые пустые куски (N=2, K=5 → 5 кусков, 3 пустых; N=0 → K пустых списков вместо `[]`).
- **count_words_chunk** — тесты зелёные. Замечание по скорости: `result += Counter(...)` на каждом тексте — `+=` у Counter проходит по всему накопленному словарю (выкидывает неположительные), это O(размер словаря) на каждый текст.
- **count_words_processes** — `UnboundLocalError` во всех трёх тестах:
  - `if __name__ == "__main__":` внутри функции: в модуле `mp_tasks` `__name__ == "mp_tasks"`, тело не выполняется, `result` не определён;
  - `pool.map(make_chunks, texts)` — make_chunks отправляется в процессы и применяется к каждой строке по отдельности, без `n_chunks`.

```python
# было
if __name__ == "__main__":
    with ProcessPoolExecutor(max_workers=n_workers) as pool:
        result = Counter()
        chunks = pool.map(make_chunks, texts)
        words = pool.map(count_words_chunk, chunks)
```
