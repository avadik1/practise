# 03 — multiprocessing

`mp_tasks.py`: план чанков (`make_chunks`), подсчёт слов по пачке в одном процессе (`count_words_chunk`) и подсчёт в пуле процессов со сбором результатов (`count_words_processes`).
Тесты: `pytest -q` из этой папки.
Почему функции в модуле, а не в ноутбуке: на macOS процессы стартуют через `spawn` — воркер заново импортирует модуль и ищет функцию по имени, а функции из ячеек ноутбука (`__main__`) ему не видны.
`experiments.ipynb`: потоки vs процессы на CPU-bound, цена пересылки (`chunksize`), изоляция памяти процессов. Прогноз пишется до запуска, вывод — после.
